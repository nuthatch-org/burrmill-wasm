Index it

This tab backfills the nest from its first block and seals it with nuthatch's own sealer, then keeps the newest blocks on top. A block is sealed only when two RPCs both call it finalized, give it one hash and return the same logs for it. That is agreement, not proof: the light client the playground uses checks headers near the head, and over a backfill it would cost more than the backfill. A young contract takes seconds to a minute. Both default RPCs served logs 60,000 blocks back (about eight days) when this page was built; publicnode keeps about 20,000 and flashbots answers older ranges with nothing, so neither is a default. An older contract needs an RPC with full history in either box.
